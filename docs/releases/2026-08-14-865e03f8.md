### inherit server fields missing from PUT payload (bug-603)

**本次变化**：fix(state): inherit server fields missing from PUT payload (bug-603)。

**实现依据**：A client loaded before a schema upgrade carries a fresh version token
(apiFetch auto-captures stateVersion from any response) but a state
object missing newer top-level keys — its full PUT passed the
optimistic-lock check and silently wiped the new fields (this lost the
owner's confirmed memory after the 2026-08-08 memories upgrade).

save_state_checked now inherits server-side values for top-level keys
the payload omits; an explicitly present key (even []) still wins, and
a stale expected_version still 409s so inherited values never land on
a losing write.

Regression tests: tests/agent/state_field_inherit_test.py (5 cases).

Co-Authored-By: Claude <noreply@anthropic.com>

**发布结果**：已随本版本进入生产；接口与公网入口由发布脚本校验。
